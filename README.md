# 爪记 PawLog · 养宠成长记录与社区

一个面向年轻养宠人的一站式「宠物成长记录 + 同城宠友」产品原型。

**在线访问**：https://avontos.github.io/pet-growth/

## 解决的问题

年轻人养宠最大的断层不是「爱不爱」，而是「养得对不对」：

1. **疫苗与驱虫是周期性的**，忘了不是懒，是没有到期提示；
2. **体重是唯一可量化的健康信号**，但没有曲线就无法判断"最近瘦了"是错觉还是事实；
3. **宠物社交的真实需求不是刷内容**，而是同城能不能约到人。

因此产品不是"宠物版小红书"，而是**以健康记录为骨架、社区为血肉**的工具型社区。

## 功能

- **健康档案**：体重曲线（含品种标准区间带）、疫苗有效期、驱虫周期进度、30 天提醒日历、自动健康小结
- **成长时间线**：每一次称重 / 接种 / 驱虫 / 分享自动落入同一条时间轴，支持按类型筛选、按月份折叠
- **地域匹配**：按城市 / 小区 / 宠物类型匹配附近宠友，**匹配度可解释**（距离、同物种、同小区、常去地点逐项给分）
- **日常分享**：发布图文动态、点赞，并同步进成长时间线
- **数据可携带**：所有记录存于本机 `localStorage`，可一键导出 JSON、一键重置

## 技术形态

- **零依赖单文件**：`index.html` 内联全部 CSS / JS / SVG 插画，无 CDN、无外链图片、无构建步骤，一个 HTTP 往返即可完整加载
- **移动端优先**：宽度 ≤ 480px 为手机布局，≥ 1024px 自动分栏（左侧产品叙事 + 右侧真机框），未用任何 UI 框架
- **路由**：`#home` / `#health` / `#timeline` / `#community` / `#me` / `#about`，可直接深链
- **演示数据以"今天"为基准生成**，任何一天打开看到的都是新鲜状态（今日待办、临期提醒、逾期项都是相对日期算出来的）

## 目录

```
index.html      # 全部产品代码（单文件）
test/smoke.js   # 无浏览器冒烟测试：抽出内联脚本 + 桩 DOM，逐视图渲染校验
```

```bash
node test/smoke.js
```

## 边界与下一步

原型阶段无账号体系、无后端、无网络请求；健康数据属强隐私，全部留在本机。上线版本应改为端侧加密 + 可选云同步，并接入疫苗本 OCR 与多宠物家庭共享。
